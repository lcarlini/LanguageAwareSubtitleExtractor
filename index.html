How to use it (no tech skills needed)

If you can copy a file into a folder, you can use this tool.

🐍

1. Install Python (once)

Download Python from python.org and, during install, check "Add to PATH".

⬇️

2. Download the tool

Get the ZIP from the button below and unzip it anywhere on your computer.

▶️

3. Double-click to run

Open the folder and run the script. The first time, it sets everything up for you.

🎬

4. Add your media

Copy your videos into the "To Process" folder that appears.

✅

5. Collect subtitles

Your subtitles appear automatically in the "Output" folder. That's it!
